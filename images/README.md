# Product images

Put product photos in this folder, then reference them from the admin panel's
Images field as `images/your-photo.jpg`.

How it works:
1. Send the photo to Lux (or add the file here yourself).
2. In the admin panel, open the product, paste `images/your-photo.jpg` into the
   image URL box, click Add, and save.

Note: Firebase Cloud Storage is not enabled on this project, so images are
hosted from this repo instead.
